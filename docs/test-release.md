# 徐霞客 macOS 测试版

这是用于产品验收的本地优先测试版本，面向 Apple Silicon Mac，最低支持 macOS 14；不支持 Intel Mac。

## 安装与启动

1. 下载 ZIP 和同名 `.sha256` 文件，并确认二者位于同一目录。
2. 在“终端”进入该目录，运行 `shasum -a 256 -c <校验文件名>`，结果应为 `OK`。
3. 解压 ZIP，把“徐霞客”拖到“应用程序”或直接双击启动。
4. 此测试版采用 ad-hoc 签名。如果 macOS 拦截，请在“系统设置 → 隐私与安全性”确认文件来源和校验值后选择“仍要打开”。不要对来源不明的副本绕过安全检查。

## 建议验收流程

1. 新建一次旅行，设置日期、目的地和时区。
2. 创建游玩、住宿、交通、餐饮、购物和其他事项。
3. 把未安排事项拖入一周 24 小时时间轴；跨日期拖动已安排事项，并拉动上下边缘调整时间。
4. 创建多晚住宿，确认入住、续住和退房日期均显示；关闭默认住宿时间后手工调整跨度。
5. 在月览打开某一天，并确认跳转到正确规划周。
6. 在详细行程表修改路线、费用、内容和重点事项，再返回规划视图确认同步。
7. 退出并重新启动应用，确认旅行和事项仍然存在。

## 数据与隐私

旅行数据仅保存在本机应用沙盒内。测试版不要求账户，不连接网络，也不申请定位、相机或用户文件访问权限。删除应用不会自动删除其沙盒数据。

## 已知限制

- 测试版没有 Developer ID 签名和 Apple 公证，不适合作为公开稳定版分发。
- 当前版本不包含 iCloud 同步、导入导出、打印或分享排版。
