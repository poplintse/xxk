# 产品愿景

## 要解决的问题

徐霞客希望让旅行者把“想做什么”快速转换为“什么时间去哪里、花多少、需要注意什么”的可执行计划，同时保留随时调整的自由。

## 当前产品原则

- 原生、轻量、快速，平台体验优先于表面一致。
- 先验证规划流程，再扩展账户、同步、协作和云服务。
- 旅行、事项和时间安排是当前核心概念，但不假设它们已是最终数据模型。
- 优先保护用户旅行数据，没有明确价值时不增加网络依赖。

## 计划平台

Android、iOS、macOS、Windows 客户端和可能的后端均在长期计划中。平台优先级、功能对齐程度、同步模式和商业模式仍待验证。

## 当前不做的假设

- 不假设所有客户端必须同时上线或功能完全一致。
- 不假设必须有账户、后端、数据库或实时协作。
- 不在用例出现前设计复杂模块、Feature 层次或跨平台抽象。
